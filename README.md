# صفحة Cram Cory

صفحة عربية ثابتة مع خادم Node.js يستقبل الطلبات، يحفظ بيانات العملاء والطلبات وبنودها في مشروع Supabase، ثم يرسل إشعارًا إلى المتجر عبر WhatsApp Business Cloud API. يتم حفظ الطلب أولًا؛ إذا فشل إشعار واتساب يبقى الطلب محفوظًا وتُسجل نتيجة الإشعار للمراجعة.

## البيانات المحفوظة

- products: بيانات المنتج والسعر بالـ DZD.
- customers: اسم العميل ورقم الهاتف الدولي.
- delivery_methods: طرق التوصيل ورسومها.
- orders: رقم الطلب، الولاية، العنوان، المبالغ، الحالة، وتوقيت الإنشاء والتحديث.
- order_items: المنتج والسعر والكمية لكل طلب.
- order_status_history: سجلّ تغيّر حالة الطلب.
- order_notifications: محاولات إشعار واتساب ونتيجتها.

الجداول مفعّل عليها Row Level Security، ولا تمنح الأدوار العامة صلاحية قراءة بيانات العملاء والطلبات. يُنفَّذ الحفظ من خادم Node.js باستخدام مفتاح Supabase السري من متغير بيئة. يحسب PostgreSQL الأسعار ورسوم التوصيل على الخادم، وليس من الإجمالي القادم من المتصفح.

## تشغيل محلي

1. ثبّت Node.js 20 أو أحدث.
2. انسخ ملف .env.example إلى .env.
3. عيّن SUPABASE_URL إلى عنوان مشروع Supabase واملأ SUPABASE_SERVICE_ROLE_KEY من إعدادات API في لوحة Supabase. **لا تضع هذا المفتاح في ملفات الواجهة أو مستودع Git.**
4. أكمل متغيرات WhatsApp أدناه إذا أردت إرسال إشعارات فعلية.
5. شغّل npm start وافتح http://localhost:4173.

فتح index.html مباشرةً عبر file:// يعرض التصميم فقط؛ إرسال الطلبات يتطلب تشغيل الخادم. لا ترفع ملف .env.

## إعداد WhatsApp Business

يلزم إعداد تطبيق Meta وربط WhatsApp Business Cloud API، ثم وضع القيم التالية كمتغيرات بيئة خاصة في الاستضافة. لا تضع Access Token في ملفات الواجهة أو في Git.

- WHATSAPP_ACCESS_TOKEN: رمز وصول الخادم.
- WHATSAPP_PHONE_NUMBER_ID: معرّف رقم الإرسال المسجل في Cloud API.
- WHATSAPP_RECIPIENT: رقم استقبال الإشعارات بصيغة دولية، أرقام فقط.
- WHATSAPP_API_VERSION: إصدار Graph API المتاح لتطبيق Meta.
- WHATSAPP_TEMPLATE_NAME: اسم قالب الإشعار المعتمد؛ القيمة المقترحة cram_cory_new_order.
- WHATSAPP_TEMPLATE_LANGUAGE: لغة القالب، والقيمة المقترحة ar.

أنشئ واعتمد قالب Utility باللغة العربية بالاسم المحدد، مع عشرة مواضع نصية بالترتيب التالي: اسم العميل، هاتفه، الولاية، العنوان، طريقة التوصيل، الكمية، سعر العبوة، قيمة المنتجات، التوصيل، الإجمالي.

## الأسعار الافتراضية

المنتج المهيأ هو Cram Cory Avocado & Aloe Vera SPF 30 بسعر 1,200 دج. رسوم التوصيل الافتراضية 700 دج للمنزل و400 دج للمكتب. المرجع النهائي للأسعار موجود في جداول قاعدة البيانات، ويمكن تغيير الأسعار والرسوم من قاعدة البيانات لاحقًا.

## الاستضافة

انشر هذا المجلد على استضافة تدعم Node.js 20 أو أحدث، واضبط أمر التشغيل على npm start. أضف SUPABASE_URL وSUPABASE_SERVICE_ROLE_KEY ومتغيرات WhatsApp في لوحة الاستضافة كإعدادات سرية، ثم اربط النطاق بـ HTTPS.

## ملاحظات أمنية

- لا تضف مفتاح service_role أو مفتاحًا سريًا إلى api-config.js أو script.js أو أي ملف عام.
- لا تمنح المتصفح صلاحيات قراءة جداول customers وorders أو سجلّات الطلبات.
- أي لوحة إدارة مستقبلية يجب أن تستخدم Supabase Auth وسياسات وصول مخصصة للمشرفين.
