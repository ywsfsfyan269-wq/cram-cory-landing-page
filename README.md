# صفحة Cram Cory

صفحة عربية ثابتة مع خادم Node.js يستقبل الطلبات ويرسل إشعارًا إلى رقم المتجر عبر WhatsApp Business Cloud API. لا ينتقل العميل إلى تطبيق واتساب. لا تظهر رسالة الشكر إلا بعد قبول Meta إرسال الإشعار.

## تشغيل محلي

1. ثبّت Node.js 20 أو أحدث.
2. انسخ `.env.example` إلى `.env` وأكمل القيم الخاصة بحساب WhatsApp Business.
3. شغّل `npm start` من هذا المجلد، ثم افتح `http://localhost:4173`.

فتح `index.html` مباشرةً عبر `file://` يعرض التصميم فقط؛ إرسال الطلبات يتطلب تشغيل الخادم.

## إعداد WhatsApp Business

يلزم إعداد تطبيق Meta وربط WhatsApp Business Cloud API، ثم وضع القيم التالية كمتغيرات بيئة خاصة في الاستضافة. لا تضع Access Token في ملفات الواجهة أو في Git.

- `WHATSAPP_ACCESS_TOKEN`: رمز وصول الخادم.
- `WHATSAPP_PHONE_NUMBER_ID`: معرّف رقم الإرسال المسجل في Cloud API.
- `WHATSAPP_RECIPIENT`: رقم استقبال الإشعارات بصيغة دولية، أرقام فقط.
- `WHATSAPP_API_VERSION`: إصدار Graph API المتاح لتطبيق Meta.
- `WHATSAPP_TEMPLATE_NAME`: اسم قالب الإشعار المعتمد؛ القيمة المقترحة `cram_cory_new_order`.
- `WHATSAPP_TEMPLATE_LANGUAGE`: لغة القالب، والقيمة المقترحة `ar`.

أنشئ واعتمد قالب Utility باللغة العربية بالاسم المحدد، مع عشرة مواضع نصية بالترتيب التالي: اسم العميل، هاتفه، الولاية، العنوان، طريقة التوصيل، الكمية، سعر العبوة، قيمة المنتجات، التوصيل، الإجمالي. لا يبدأ الخادم بإرسال الطلبات ما لم تكتمل متغيرات WhatsApp.

بيانات السعر والحساب تُعاد على الخادم: العبوة 1,200 دج، والتوصيل للمنزل 700 دج أو للمكتب 400 دج. لا يعتمد الخادم على إجمالي أرسله المتصفح.

## الاستضافة

انشر هذا المجلد على استضافة تدعم Node.js 20 أو أحدث، واضبط أمر التشغيل على `npm start`. أضف متغيرات WhatsApp في لوحة الاستضافة كإعدادات سرية، ثم اربط النطاق بـ HTTPS. لا ترفع ملف `.env`.
